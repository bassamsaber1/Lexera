# Lexera – Egypt Legal System

منصة قانونية داخلية (Arabic-first) للبحث والتحليل والمساعدة القانونية **غير الإفتائية**.

> ⚠️ هذا النظام لا يقدم استشارات قانونية أو فتاوى، ولا يصدر قرارات قانونية آلية.

## الأقسام الرئيسية

- **قسم تحليل عقود**
- **قسم تحليل قضايا ودفوع**
- **قسم إنشاء مذكرة دفاع**
- **قسم البحث في موقع lawegypt.net** مع حفظ المواد في **ملفاتي**
- **قسم شات مفتوح**
- **لوحة Admin احترافية** لإدارة كل شيء

## إدارة المستخدمين (Admin)

- إضافة مستخدمين جدد
- حذف مستخدمين
- تفعيل / إلغاء تفعيل
- إضافة ملاحظات مخالفات
- إدارة صلاحيات Override لكل مستخدم
- إضافة توكنات للمستخدمين
- حماية من حذف/تعطيل آخر Admin

## نظام التوكنات

يتم خصم توكنات تلقائيًا من المستخدم عند استخدام:
- تحليل العقود
- تحليل القضايا والدفوع
- إنشاء المذكرات
- الشات المفتوح

وعند نفاد الرصيد يتم حجب العملية لحين زيادة التوكنات بواسطة Admin.

## إعدادات التكامل مع Groq API

اضبط متغيرات البيئة التالية قبل التشغيل:

```bash
export LEXERA_API_BASE_URL="https://api.groq.com/openai/v1"
export LEXERA_API_KEY="<YOUR_GROQ_KEY>"
export LEXERA_MODEL="llama-3.3-70b-versatile"
export LEXERA_API_TIMEOUT="60"
```

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

## بيانات الدخول الافتراضية لأول تشغيل

- Username: `admin`
- Password: قيمة `LEXERA_ADMIN_PASSWORD` إن وُجدت، وإلا `Admin@12345`

> يفضل تغيير كلمة المرور الافتراضية فور التشغيل الأول.

## ملاحظة حول البحث في lawegypt.net

تكامل البحث يعمل بأسلوب **HTML parsing (best effort)** وقد يحتاج تحديث إذا تغيرت بنية الموقع.
